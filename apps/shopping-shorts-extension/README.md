# 쇼핑쇼츠 Chrome Extension

쇼핑쇼츠 전용 격리 Extension입니다.

## 로드 방법

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. 이 폴더를 선택합니다.

```text
apps/shopping-shorts-extension
```

## 동작 범위

- 사용자가 직접 연 현재 쿠팡 탭에서만 실행합니다.
- 서버에서 쿠팡으로 요청을 보내지 않습니다.
- 자동 페이지 순회, 백그라운드 반복 수집, 쿠키 수집을 하지 않습니다.
- 1차 버전은 추출 JSON을 클립보드로 복사합니다.
- 쇼핑쇼츠생성 화면의 JSON 가져오기 영역에 붙여넣어 저장합니다.
